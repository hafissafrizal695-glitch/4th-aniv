Project Guide & Customization

Halo! Website ini dirancang khusus sebagai hadiah ulang tahun hubungan ke-4 untuk Sayang. Berikut panduan ringkas cara mengaturnya:

1. Struktur Folder (Sesuai Permintaan)

anniversary-website/
├── index.html (File utama yang berisi seluruh kode)
├── assets/
│   ├── images/ (foto1.jpg - foto6.jpg)
│   └── music/ (romantic.mp3)
└── README.md

2. Cara Memasukkan Foto

Simpan 6 foto terbaik kalian di folder assets/images/ dengan nama foto1.jpg sampai foto6.jpg. Jika foto belum ada, website otomatis menampilkan placeholder elegan.

3. Cara Memasukkan Musik Latar

Letakkan file musik format MP3 Anda di assets/music/romantic.mp3. Ketika tombol "OPEN MY SURPRISE" ditekan, musik akan mulai dimainkan dengan mulus.

4. Cara Mengubah Surat Cinta

Buka bagian script JavaScript di file ini, cari variabel loveLetterText, dan Anda bisa langsung mengubah kalimatnya sesuai keinginan.

5. Cara Deploy ke GitHub Pages / Vercel

Upload seluruh folder ke repository GitHub, lalu aktifkan GitHub Pages di pengaturan repository, atau import langsung ke Vercel untuk hosting instan gratis.
